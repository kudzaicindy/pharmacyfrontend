# Portal alert sounds

Served from `public/sounds/` at:

| File | When it plays |
|------|----------------|
| `new-request.mp3` | New patient medicine **request** |
| `new-reservation.mp3` | New patient **reservation** |

Replace these files to change the alert tone. Keep the same filenames so the pharmacy dashboard picks them up automatically.

Source: `Notification Sound Effects Copyright Free.mp3` (bundled copy).
